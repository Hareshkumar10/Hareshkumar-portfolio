A multilingual jewellery catalogue concept and implementation for Kawshalya Jewellers, with English, Tamil, and Sinhala content. Live stock and launch readiness depend on shop-owner review.

Languages & technologies

TypeScript, React, Vinext, CSS/Tailwind, Drizzle ORM, SQL, Cloudflare Workers, and D1 SQLite.

Application structure

React storefront and admin UI → server-side API handlers and validation → Drizzle queries → D1 database.

  • app/storefront.tsx — catalogue and product details.
  • app/admin/ — protected product and gold-rate editor.
  • app/api/ — catalogue reads and admin mutations.
  • lib/ — translations, validation, authorization, and WhatsApp enquiry formatting.
  • db/schema.ts and drizzle/ — schema and migrations.
  • tests/ — validation and HTTP checks.

Key features

Product and stock management, draft/published items, LKR prices, 22K/24K gold rates, language switching, and WhatsApp product enquiries. No checkout or online payment processing.
